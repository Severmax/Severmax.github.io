TikTok Live Tower Defense

Інтерактивна tower defense для ефіру: глядачі впливають на бій у реальному часі.

Відкрити в TikTok

Про продукт

Гра для стрімерів TikTok LIVE у форматі 9:16 під OBS. Глядачі спавнять монстрів через ефір (коментарі, лайки→meter, гіфти), а автономний герой сам цілиться й захищає місто. Стрімер у бій не втручається — тримає ефір і керує сесією з окремої адмін-панелі.

Геймплей

  • Одне місто з HP внизу екрана; монстри йдуть вертикальною доріжкою зверху вниз
  • Типи монстрів: weak / strong / boss; нік глядача над юнітом
  • Герой стоїть збоку перед містом і стріляє автоматично
  • Heal-гіфт може підлатати місто; HP = 0 → кінець раунду
  • Рестарт і спавн — з Admin-вікна (не в стрімі)

Для стрімера

  • Game-вікно 9:16 для Window Capture в OBS
  • Окрема Admin-панель: спавн, рестарт, статус LIVE
  • Підключення LIVE webhook / like meter
  • Мапінг TikTok-подій на типи монстрів (gift map)

Технології

  • Flutter Desktop (macOS) — app shell і два вікна
  • Flame — ігровий цикл, спрайти, колізії
  • LiveEventSource — mock і TikTok connector через event stream
  • Spawn queue — тротлінг спавну без блокування game loop

Статус і продаж

Зараз проєкт не розвивається. Готове ядро гри + Admin + LIVE-інтеграція (phase 0–6 майже закриті). Можу продати права власності за фіксовану суму або за відсоток від майбутнього доходу (revenue share) — якщо цікаво запустити продукт далі або інтегрувати у свій стрім-бренд.
