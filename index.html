Мобільні продукти з відчуттям якості — від ідеї до публікації.

Розробляю кросплатформні застосунки на Flutter для Android та iOS. Закриваю повний цикл: архітектура, UI за макетами, Firebase / бекенд-інтеграції, авторизацію, підписки, аналітику та публікацію в App Store і Google Play.

Працюю з продуктами різного масштабу — від MVP до застосунків із тисячами користувачів. Окремо розвиваю власні продукти.

  • Монетизація: RevenueCat, In-App Purchases, динамічні paywall
  • Дані й інфра: Firebase, Supabase, Cloud Functions, Remote Config
  • Якість: Clean Architecture, Bloc/Cubit, тести, стабільні релізи

01

Стартап · iOS / Android · 60 000+

Тиша — медитації українською

Мобільний застосунок з медитаціями: практики для спокою, роботи з тривогою та щоденної турботи про психічне здоров’я.

Розробка, техпідтримка й масштабування. Єдине логування подій у Mixpanel і Firebase, підписки та динамічні paywall через RevenueCat, Cloud Functions, Remote Config, pixel-perfect UI з Figma та внутрішні автотести.

#flutter#firebase#revenuecat#mixpanel#figma
02

Lead · повний цикл · App Store + Google Play

MyNames — твоя візитка

Цифрові візитки з QR і живим профілем. Повна розробка з нуля — від архітектури до публікації в сторах.

Firebase, drag-and-drop редактор, RevenueCat + webhooks, Sign in with Apple/Google і промо-лендинг продукту.

#flutter#firebase#revenuecat#oauth#landing
03

Flutter Web · кабінет · my-names.com.ua

MyNames Web

Веб-кабінет для керування цифровими візитками, QR-кодами та статистикою. Split-screen логін з Google / Apple, спільні дані з мобільним застосунком через Firestore.

Desktop-first UX: візитки, архів, налаштування, редактор із live preview, аналітика (перегляди, шери, QR, кліки), тарифи та оплата через RevenueCat Web Billing.

#flutterweb#firebase#oauth#revenuecat#analytics
04

Ініціатор · MVP · Clean Architecture

Together Tales — застосунок для пар

Гейміфікований застосунок для пар: спільні завдання, поради та «привітатися» одним дотиком. Самостійно від ідеї до MVP.

Cubit/Bloc, Clean Architecture, Firebase Auth, зв’язування пари за кодом, Supabase для даних і синхронізації.

#flutter#bloc#supabase#firebase#mvp
